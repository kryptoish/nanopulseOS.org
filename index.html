A tiny operating system with a pulse.

          
nanopulseOS is a hobby kernel for 32-bit x86, written from scratch in C and assembly. It boots from a USB stick, runs entirely in RAM, and leaves nothing behind when you power off. It comes with generative art, retro games and a small shell.

$ cat INSTALL.md


      
nanopulseOS runs from a USB stick, and nothing is installed on the machine. Flashing takes about a minute.


      
    
        
  1. 
          
    00 what you need
    
          
      
            
    • a 32- or 64-bit x86 PC that can do legacy BIOS boot (often called CSM)
      • 
            
    • any USB stick. The image is about 16 MB, but everything on the stick will be erased
      • 
            
    • Secure Boot turned off
      • 
          
    
        
    2. 

        
  2. 
          
    01 download the image
    
          
    
            
              ↓nanopulseos.iso.iso
            
          
    
          
    curl -LO https://nanopulseos.org/nanopulseos.iso
    
          
    To check the file, type sha256sum nanopulseos.iso in the shell at the bottom and compare it with yours.
    
        
    3. 

        
  3. 
          
    02 flash it
    
          
    
            
            
            
          
    

          
    
            
    # find your stick (e.g. /dev/sdb). Pick the whole disk, not a partition.
    
            
    lsblk -d -o NAME,SIZE,MODEL
    
            
    sudo dd if=nanopulseos.iso of=/dev/sdX bs=4M status=progress oflag=sync
    
            
    # replace /dev/sdX. Choosing the wrong disk will wipe it.
    
          
    

          
    
            
    # find your stick (e.g. /dev/disk4), then unmount it
    
            
    diskutil list external
    
            
    diskutil unmountDisk /dev/diskN
    
            
    sudo dd if=nanopulseos.iso of=/dev/rdiskN bs=4m
    
            
    # rdisk (raw disk) is much faster than disk. Eject when done.
    
          
    

          
    
            
    # use Rufus
    
            
    
              
    boot selection
    nanopulseos.iso
    
              
    partition scheme
    MBR
    
              
    target system
    BIOS (or UEFI-CSM)
    
              
    on START
    choose Write in DD Image mode
    
            
    
            
    # balenaEtcher also works on any OS: select the image, pick the stick, flash.
    
          
    
        
    4. 

        
  4. 
          
    03 boot it
    
          
      
            
    • Plug in the stick and reboot.
      • 
            
    • Open the firmware menu, usually F2 F12 Del or Esc during POST.
      • 
            
    • Turn on Legacy / CSM and turn off Secure Boot.
      • 
            
    • Pick the USB stick from the boot menu. GRUB shows up, waits 3 s, then loads the kernel.
      • 
            
    • Type help at the > prompt.
      • 
          
    
        
    5. 

        
  5. 
          
    04 if it won't boot
    
          
    
            
    skips the usb
    Your machine is probably UEFI-only. Many PCs made after about 2020 have no CSM, and nanopulseOS needs legacy BIOS boot.
    
            
    black screen
    Try another USB port, or turn on CSM / "legacy option ROMs" for the graphics card.
    
            
    no keyboard
    The kernel talks to PS/2. Most laptops emulate it, but some USB keyboards need "USB legacy support" turned on in the firmware.
    
            
    no hardware?
    qemu-system-i386 -cdrom nanopulseos.iso, or just boot it here.
    
          
    
        
    6.

A NANO programmed OS that has Pulse.

        
nanopulseOS is a learning project: a minimal, flat, text-first operating system in the spirit of older machines. It boots from a USB stick and makes room for things that are just fun, like generative art, small games and easter eggs.
