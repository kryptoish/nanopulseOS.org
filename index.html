A tiny operating system with a pulse.

          
nanopulseOS is a hobby kernel for 32-bit x86, written from scratch in C and assembly. It boots from a USB stick, runs entirely in RAM, and leaves nothing behind when you power off. It comes with generative art, retro games and a small shell.

    linux: find your stick (e.g. /dev/sdb). Use the whole disk, not a partition like sdb1.
    
          
    lsblk -d -o NAME,SIZE,MODEL
    
          
    sudo dd if=nanopulseos.iso of=/dev/sdX bs=4M status=progress oflag=sync
    
          
    macos: find your stick (e.g. /dev/disk4), unmount it, then write to the raw rdisk, which is much faster.
    
          
    diskutil list external
    
          
    diskutil unmountDisk /dev/diskN
    
          
    sudo dd if=nanopulseos.iso of=/dev/rdiskN bs=4m
    
          
    windows: Rufus, MBR, write in DD image mode.

NAME

      
nanopulseos: the guest shell you get after boot


      
SYNOPSIS

      
> command [args]. Commands are case-insensitive. Paths are absolute and start at /.


      
FILESYSTEM

      

        
ls [path]
list a directory (default /)

        
mkdir <path>
create a directory

        
rmdir <path>
remove an empty directory

        
touch <path>
create an empty file

        
rm <path>
delete a file

        
cat <path>
print a file

        
write <path> <txt>
overwrite a file with text

        
stat <path>
show file or directory info

        
df
show block and inode usage

      


      
PROGRAMS

      

        
art
generative fingerprint (Ctrl+C / Esc to exit)

        
tetris
play tetris and earn coins (Ctrl+C to exit)

        
portal
"Still Alive" on the PC speaker (Ctrl+C to exit)

        
gamble
open cases of error-message skins with your coins

        
inventory [recent]
list your skins, sorted by rarity or by most recent

      


      
MISC

      

        
echo <text>
print text

        
clear
clear the screen

        
help
list all commands

      


      
BUILDING

      

        
You need an i686-elf GCC cross-compiler, nasm, grub, xorriso and mtools. The full walkthrough is in docs/build-instructions.md.
