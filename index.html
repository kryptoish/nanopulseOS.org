Install Instructions

  1. Download nanopulseos.iso.
  2. Flash it to a USB stick. This erases everything on it.

    Linux: find your stick (e.g. /dev/sdb). Use the whole disk, not a partition like sdb1. 
    lsblk -d -o NAME,SIZE,MODEL
sudo dd if=nanopulseos.iso of=/dev/sdX bs=4M status=progress oflag=sync
    macOS: find your stick (e.g. /dev/disk4), unmount it, then write to the raw rdisk. 
    diskutil list external
diskutil unmountDisk /dev/diskN
sudo dd if=nanopulseos.iso of=/dev/rdiskN bs=4m
    Windows: use Rufus, MBR, write in DD image mode.

  3. Turn on legacy/CSM boot, turn off Secure Boot, and boot from the USB. Then type help.
